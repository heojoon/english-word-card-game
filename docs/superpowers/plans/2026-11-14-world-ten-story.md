# 월드10 이야기 집필 계획

**목표:** 승인된 「별빛이 끊긴 관측탑」을 기존 원고 형식의 다섯 편으로 완성한다.

**승인 근거:** 동쪽 옛 관측로 진입 → 수호병기와 실종 경비대 구조 → 거짓 구조 신호를 보내는 천사의 부하와 전투 → 요새로 향한 관측 기록 확인이라는 제안에 사용자가 동의했다.

**구성:** `assets/novel/world-10-scenario.md`에 줄거리·인물·연속성 기준을 두고, 같은 폴더에 프롤로그와 중간·최종보스 조우·승리 원고를 각각 작성한다. 게임 연결, 이미지·음악 생성, 전투 수치와 보상 설계는 이번 범위에 포함하지 않는다.

## 집필과 검수

- [x] 개요와 인물, 거짓 신호의 목적과 한계를 정리한다.
- [x] 프롤로그와 중간보스 조우·승리를 작성해 실종 경비대 구조를 완결한다.
- [x] 최종보스 조우·승리를 작성해 관측탑 탈환과 다음 여정의 단서를 완결한다.
- [x] 월드9 끝 장면과의 연결, 네 사람과 다크 소서러스의 관계, 기술과 성흔의 파편의 한계를 검수한다.
- [x] 여섯 원고의 존재, 상대 링크와 장면 순서, 변경 범위를 확인한다.

## 집필 판단

- 분기별 기억·유물에 의존하지 않는 공통 줄거리로 작성한다.
- 수련의 성과는 역할 교대와 짧은 신호로 보여 주며 합체 공격이나 신규 기술을 추가하지 않는다.
- 천사의 부하는 새 인물로 설정하며 바르가스의 탈주를 전제하지 않는다.
- 관측 기록은 최근 특정 시점의 이동을 증명한다. 천사의 현재 위치·타락 원인·봉인 해제자를 모두 아는 기록으로 만들지 않는다.
- 문서 작업이므로 소프트웨어 테스트·빌드 대신 원고와 링크를 검수한다. 기존 작업 파일은 수정하지 않는다.

## 검수 기록

- 다섯 본문 총 21개 장면의 번호가 연속이며, 개요를 포함한 여섯 원고의 상대 링크 9개가 모두 존재함을 확인했다.
- 네라의 구속 해제, 경비병 세 명의 이동과 인계, 마지막 신호 전 네라의 관측탑 복귀를 본문에 명시했다.
- 기존 수정 파일 `crystal-game.css`, `story-novel.js`와 다른 미추적 자산은 건드리지 않았다. 커밋·게임 연결·배포는 진행하지 않았다.
