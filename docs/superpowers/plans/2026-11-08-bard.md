# 은유시인 Implementation Plan

**Goal:** 하프와 음표 투사체를 사용하는 남녀 은유시인 플레이어 직업을 추가한다.
**Architecture:** 기존 직업 선택·능력치·공용 액티브 시스템을 확장하고, 독립 캐릭터/투사체 SD 레이어를 사용한다.
**Tech Stack:** static JS/CSS, Node tests, PNG/Pillow asset packing, linked Supabase.
**Spec:** 사용자 요청 및 이 문서. 디자인·스킬 결정은 사용자에게 위임받음.

## Global Constraints
- bard 초기 HP3/MP2/ATK4/LUK2, 성장 HP2.9/MP3.5/ATK5.8/LUK1.6. EXP 계산은 기존 공통 함수 사용.
- 패시브 이어지는 선율: 정답 누적 5회마다 MP1, 최대 MP 제한. 오답으로 누적 횟수를 초기화하지 않는다.
- 액티브 치유의 아리아: 시작부터 사용 가능, MP1로 HP2 회복, 최대 HP 제한. 풀 HP·일시정지·종료·피버·입력 잠금 중 사용 불가.
- 남녀 정체성은 concept/char_bard_male_female_harp_concept_v1.png 기준. 프로필에 SD 사용 금지.
- idle 2프레임, attack 6프레임(마지막 능동 연주), hit 3프레임(마지막 완전 다운), projectile 6프레임.
- 캐릭터 320×320 anchor(.5,.975), 투사체 320×320 anchor(.5,.5), 오른쪽 방향. 소스/리뷰 gap 정확히 50px, 런타임 gap0.
- 피해는 투사체 접촉에서 발생. reduced motion 동일 순서. 기존 미커밋 변경 보존. 배포/커밋 요청 없음.
