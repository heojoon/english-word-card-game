# 월드 10 지도와 스테이지 적용

사용자 요청: 월드 10 원고를 확인해 본편 40단계, 스펠링 30문제, 20·40단계 보스와 선택 갈림길 보스를 적용한다.

기존 chapter 10은 월드 7C이므로 내부 chapter 13을 사용한다. 원고의 루멘·세이런과 다섯 이야기 연결을 보존한다. 제작 판단으로 20단계 이후 선택형 번외 3단계를 추가하고 마지막에 폐신호소 수호기 아스트라를 둔다. 번외는 본편 진행 조건에서 제외한다. 신규 보상이나 DB 변경은 하지 않는다.

- [x] 양 학습 수준의 40+3단계, 30문항, 공유 기록과 분기 해금 회귀 검증 작성.
- [x] 원본 월드 1 그림체로 43개 수정의 세로 지도를 생성하고 원본·실측 좌표·프롬프트 기록 저장.
- [x] chapter 13 콘텐츠, 지도, 순서·선택 분기·기존 Type C 전투·HP 보스 연결.
- [x] 본편 다섯 원고와 번외 조우·승리 원고를 소설 번들에 연결.
- [x] 관련 회귀 검증 70개 및 빌드 통과. 브라우저 검사는 사용자 요청이 없어 실행하지 않는다.

일반전은 30문항/180초. 보스는 30문항 덱을 순환하며 루멘 HP 200, 세이런 HP 240, 아스트라 HP 180, 정답 접촉 시 DMG 피해·HP 0 승리와 공용 액티브를 유지한다. 전용 보스 SD는 이번 지도 제작 범위 밖이므로 명시적인 임시 수정 표현을 사용한다.

검수: 375px 정적 좌표 오버레이를 확인했다. 이전 소설 번들의 모든 기존 키가 동일함을 비교했다. 계정 저장은 기존 `award_game_result`를 사용하며 월드 9 전용 보스 RPC와 월드 8/9 룰렛 RPC를 호출하지 않는다. DB 변경·배포는 수행하지 않았다.
