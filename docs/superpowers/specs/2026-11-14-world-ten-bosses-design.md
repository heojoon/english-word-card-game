# 월드 10 중간·최종보스 제작 명세

상태: 사용자 세부 설계 승인 완료(2026-11-14), 구현·오프라인 검수 완료. 브라우저 검수는 요청되지 않음.

## 목표와 범위

사용자는 루멘·세이런의 스탠딩, SD 애니메이션, 전투 스킬 제작과 실제 게임 적용을 선택했다. 기존 월드 10 임시 수정 표시를 각 보스의 전용 자산과 동작으로 교체한다. 배포는 이번 범위에 포함하지 않는다.

## 검토한 접근

- 스탠딩만 먼저 제작: 외형 검토는 빠르지만 전투의 임시 수정 표시가 남는다.
- 스탠딩·SD·스킬까지 제작하고 적용: 외형과 전투를 함께 완성한다. 사용자가 선택한 범위다.

아래 스킬 수치와 세부 외형은 기존 원고에 근거한 제작자 제안이며 사용자 확정 사항과 구분한다.

## 보스 계약

- Type C, 학습 수준별 기존 어휘와 30문항 순환 덱 유지. 기본 시간은 기존 `ceil(HP / DMG) × 6초` 유지.
- 정답 접촉에서 현재 캐릭터 DMG를 한 번 적용하며 보스 HP 0만 승리로 판정한다. 방어 고리는 공용 추가 피해를 포함한 보스 피해 진입점에서 적용하고 소수 HP를 허용해 DMG 1도 유효하게 한다. 표시 HP는 소수점 한 자리까지 표시한다.
- 여러 HP 임계치를 넘으면 높은 임계치부터 대기열에 넣는다. 주기 스킬과 겹치면 진행 중 동작을 마친 후 순서대로 실행한다. 스킬 예고·실행 중 입력을 잠그고, 문제/보기 이동과 기존 플레이어 접촉이 겹치지 않게 한다.
- 플레이어 피해는 기존 액티브·펫 방어 경로를 사용한다. 오답은 같은 문제에 재도전하며 오답 공격과 예약 스킬의 접촉은 각각 한 번만 발생한다.
- 일시정지는 모든 동작을 멈춘다. 아이스 타임·펫 시간정지는 카운트다운·보스 주기·예고·방어 지속·idle을 멈추고 진행 중인 플레이어 공격 접촉·피격은 완료한다. 아이스 타임 MP 1, 공용 얼음 효과와 1.2초 안내, 정답/오답 해제, 포션 후 재사용을 유지한다.
- HP 0·시간 만료·퇴장·재시작에서 잔여 스킬과 지연 피해를 취소한다. 재시작으로 HP/MP를 회복하지 않으며 최종보스 승리 회복은 유지한다.
- 기존 보상·공유 기록·원고·지도·번외 아스트라 규칙을 유지한다. 새 전용 보상, 스킬 해금, DB 변경, 신규 음악은 추가하지 않는다.

## 자산과 구현

- Direction 01 Crystal Quest의 부드러운 2D 판타지로 제작한다. 승인된 기존 보스 스탠딩·SD를 화풍 참조로 검사하고, 각 신규 스탠딩을 해당 SD의 외형 기준으로 사용한다.
- 스탠딩: `assets/novel/characters/char_{lumen,seiran}_world10_standing.webp`.
- SD: `assets/monsters/world-10/{lumen,seiran}/`. idle 3장, attack 3장, hit 3장, skill 3장을 기본으로 하며 루멘은 방어 고리 상태를 추가한다. hit는 알아차림→강한 반동→완전 다운이고 마지막 자세를 유지한다.
- 왼쪽 방향, 기본 320×320 RGBA 셀, 앵커 (0.5, 0.975). 팔·고리·무기·효과가 잘리면 셀만 확장하고 캐릭터 크기는 유지한다. 일반 피격은 앞 두 장, 최종 다운은 세 장 모두 사용한다.
- 원본·프레임·런타임 strip·검수 합성물을 분리하고 JSON에 실제 셀, 타이밍, 접촉 이벤트와 프롬프트·참조·검수 상태를 기록한다. 정확한 셀 확장량·프레임별 지속시간·보조 효과 표현은 제작자가 실측 후 정한다.
- 기존 `world-nine-boss.js`의 월드 10 임시 위임 경로를 확인하고 전용 월드 10 모듈로 분리한다. `crystal-game.js`에서 진입·질문·정답·공용 피해·tick·렌더·결과·정리를 연결하고 CSS·스크립트 의존 순서·빌드 파일 목록을 동기화한다. 월드 9와 아스트라 동작은 보존한다.
- 기존 미커밋 변경은 보존하고 이번 변경 부분만 검토한다.

## 검증

- 변경된 보스 경로에 필요한 회귀 검사: DMG 4 접촉 전후 HP, 고정 30문항 이후 진행, HP 0 승리, 방어 적용/종료, 주기·임계치·큰 delta 순서, 오답·중복·퇴장 후 지연 피해 방지.
- 아이스 타임 정지·공용 표시·해제·포션 후 재사용과 공용 피해/방어 연결을 확인한다.
- 전체 프레임 투명도·경계·크기·바닥선·JSON 일치·다운 마지막 유지·reduced motion을 오프라인 검수한다. 생성 기술 검수는 사용자 외형 승인으로 기록하지 않는다.
- `npm run build` 실행. 브라우저 검사는 사용자 요청 시만 실행하며 미실행 여부를 완료 보고에 명시한다.
