# 월드 11 · 낙성 요새의 마지막 수송

상태: 사용자 설계 승인 완료(2026-11-22). 사용자는 수준 우선, 짧은 표현 확장과 스테이지 간 복습 재사용을 선택했으며 인터넷 자료를 검색해 어휘 수준을 선정하도록 요청했다. 구현·오프라인 회귀·모바일 지도 검증·빌드 완료. 보스 브라우저 플레이 검사는 미요청.

## 목표와 확정 요구

- 월드 11을 실제 플레이 가능한 44단계 지도로 추가한다.
- 초등학생은 초등학교 3학년, 중학생은 중학교 2학년 수준으로 별도 문제 풀을 만든다. 각 수준은 44단계 × 30항목 = 1,320항목이며 총 2,640개 배정 항목이다. 이는 서로 다른 단어 2,640개라는 뜻이 아니다.
- 스토리는 영어와 한국어 뜻 연결하기다. 같은 문제 풀로 서바이벌에 새 연습 월드를 만들고 기존 4지선다 플레이를 유지한다.
- 22단계에 쇄문장 가렐, 44단계에 병참관 오르덴이 등장한다. `assets/novel/world-11-*.md`의 다섯 편을 적용한다.
- 학습 수준을 바꾸어도 스토리 해금·클리어·재플레이 기록은 공유한다.

## 접근과 선택 근거

1. 스토리와 서바이벌 문제를 별도 복제하면 번역·배정이 달라질 수 있다.
2. 수준별 44개 어휘 맵을 한 번 정의하고 두 모드가 공유하면 동일 자료로 예습·복습할 수 있다. 사용자의 ‘만든 문제 풀을 서바이벌에도’ 요구에 맞는 접근으로 제안한다.

사용자는 문제 수를 채우기 위해 난도를 올리는 방식 대신 기초 어휘·짧은 표현·복습 재사용을 선택했다. 영어/한국어 쌍은 직접 편집하며 교재의 예문·번역·문항 구성은 복제하지 않는다.

한국 학년과 CEFR은 일대일 대응이라고 주장하지 않는다. 국내 학년 자료의 주제·표현 범위를 우선하고 국제 목록은 후보 어휘의 난도 보조 기준으로 사용한다. 최종 자료에는 선정 항목의 출처 ID, 수준, 주제, 원형/확장 표현 구분과 배정 내역을 남긴다. 실제 확인하지 않은 어휘를 특정 목록에 실렸다고 표시하지 않는다.

### 초등 풀

- 익숙한 구체 명사·기초 동사·형용사, 인사와 교실 표현, 수·색·가족·동물·음식·날씨를 중심으로 편집한다.
- 기존 기초 단어를 사용한 짧은 소유·수량·행동 표현을 허용한다. 숫자나 색깔만 기계적으로 바꿔 1,320항목을 채우지 않는다.
- 긴 문장, 추상적인 전투 용어, 어려운 시제·관계절·가정법을 난도 충족 수단으로 쓰지 않는다. 요새 이야기의 단어를 초등 어휘에 강제로 넣지 않는다.
- 각 단계는 주제 중심 항목과 앞선 학습 내용 복습을 섞되, 같은 단계 안에는 같은 영어 또는 같은 한국어 정답을 중복 배정하지 않는다. 복습은 단계 사이에 허용한다.

### 중등 풀

- 학교·우정·건강·봉사·여행·환경·기술 등 중2 주제에 맞는 어휘·구동사·짧은 표현을 선별한다.
- 단어의 여러 뜻 중 하나를 명확히 정한다. 영어와 한국어가 같은 의미·품사로 연결되도록 직접 검토한다.
- 초등 풀을 그대로 중등 풀로 복사하지 않는다. 필요한 기초 복습을 허용하되 중등 주제와 어휘가 실질적으로 구분되게 한다.

### 자료 형식과 품질

- 수준별 원본 자료와 생성 스크립트를 저장소에 두고, 각 44개 맵의 30개 항목을 재현 가능하게 출력한다. 실행할 때마다 스테이지별 어휘가 바뀌지 않게 한다.
- 기존 `[영어, 분류 라벨, 한국어 뜻]` 형식과 로컬 스크립트·원격 갱신·Android 번들 경로를 함께 맞춘다. 코드 확인 결과 두 번째 값은 보기 앞에 표시되는 분류이므로 `단어`/`표현`을 쓰고 발음은 제공하지 않는다. 영어 원문을 두 번째 값으로 넣어 정답을 노출하지 않는다.
- 단계별 영어/한국어 중복, 빈 값, 수량, 수준 오배정과 같은 보드의 정답 모호성을 검사한다.
- 출제 셔플은 허용하되 저장된 30개 항목 전체를 한 번 소진한 뒤 반복한다.

## 지도와 진행

- 화면 월드 11은 기존 월드 8의 내부 chapter 11과 구분한다. 새 내부 chapter는 14, 스테이지 키는 `story-ch11-1`~`story-ch11-44`로 제안한다.
- 기록명은 `스토리 11장 N · 낙성 요새의 마지막 수송`으로 하고 학습 수준 접미사를 붙이지 않는다.
- 월드 10 본편 40단계 클리어 후 열린다. 번외 3단계 클리어를 요구하지 않는다. 이후 앞 단계 완료로 다음 단계가 열린다.
- 지도는 상단 옛 보급로 → 하역장 → 22단계 쇄문 → 위층 점검로 → 수송 마당 → 하단 44단계 동문 순서다. y 좌표는 진행 순서대로 증가한다.
- 원본 월드 1 지도를 스타일 참조로 사용해 Crystal Quest 화풍의 새 지도를 제작한다. 정확히 44개 웨이포인트와 모바일 버튼 간격을 확보한다. 지도 비율·실제 좌표는 생성 후 측정하여 확정하고 원본·런타임 WebP·프롬프트·메타데이터·검수물을 분리한다.
- 모바일에서 44단계를 세로로 탐색할 수 있도록 기존 지도 스크롤과 현재 단계 이동을 유지한다.

## 연결하기와 서바이벌

- 일반 스토리: 5쌍 연결 보드 × 6회 = 30문제. 한 쌍을 맞히면 1문제로 기록한다.
- 일반 스토리 제한시간은 총 180초를 제작자 기본값으로 제안한다. 기존 오답·HP·MP·정답 접촉·능력·포션·효과 규칙을 사용한다.
- 서바이벌에 ‘낙성 요새 연습’ 월드와 44개 단계가 표시된다. 사용자의 학습 수준에 맞는 30개 항목을 해당 단계에서 사용한다.
- 서바이벌은 기존 영→한/한→영 4지선다와 제한시간·오답·기록·보상 규칙을 유지한다. 연결하기나 보스전으로 바뀌지 않는다.
- 서바이벌 연습은 스토리 선행 클리어 없이 이용한다. 서바이벌 기록으로 스토리를 해금하지 않는다.
- 보기는 서로 다르고 정답과 겹치지 않게 한다. 동의어처럼 두 정답이 성립하는 항목은 같은 문항 보기에 넣지 않도록 검토한다.

- 아이스 타임은 MP 1, 공용 오버레이와 1.2초 안내, 실제 카운트다운·idle 정지, 오답·5쌍 보드 완료·퇴장 시 해제, 포션 후 재사용을 지원한다. 진행 중 접촉·피격은 읽을 수 있게 유지한다.

## 계정 저장과 배포 경계

- 게스트/데모와 계정 모드를 모두 연결한다. `localStorage`로 계정의 권한·보상 검증을 대체하지 않는다.
- 기존 점수 저장·보상 RPC가 새 월드의 기록을 허용하는지 확인한다. 필요한 경우 월드 11 등록과 서버 검증을 migration으로 추가하고, 소유권·선행 완료·중복 보상 방지·원자 처리를 유지한다.
- 새 특별 보스 보상은 만들지 않는다. 일반 기록·보상 체계가 허용하는 정책을 적용하고 클라이언트와 서버를 일치시킨다. 월드 11의 첫 보상/재플레이 지급 수치는 기존 RPC 정책을 확인한 뒤 명세에 기록한다.
- DB 변경이 필요하면 저장소 지침대로 연결된 운영 DB만 사용한다. 변경 전 pending migration 목록과 dry-run을 검토하며 unrelated migration을 묵시적으로 적용하지 않는다.
- GitHub Pages 푸시와 Android 배포는 이번 요청에 포함되지 않는다. 빌드 산출물은 동기화한다.

## 검증과 완료 기준

- 필요한 검사만 추가한다: 두 수준 각각 44×30, 단계 내 중복/빈 값, 출처 메타데이터, 같은 풀의 두 모드 연결, 5×6 보드와 4지선다, 수준 전환 후 기록 공유, 월드 10→11 해금, 22/44 이야기 분기.
- 보스 DMG 접촉 전후 HP, 30문항 이후 순환, HP 0 승리, 중복 입력·종료 후 피해 방지, 아이스 타임 정지·해제·재사용을 회귀 검증한다.
- 자산 경로·투명 alpha·셀 경계·프레임 JSON·마지막 다운 유지와 지도 44좌표를 검수한다. 지도 통합 지침에 따라 모바일 지도/버튼 정렬을 브라우저로 확인한다. 보스 브라우저 플레이 검사는 별도 요청 시 수행한다.
- `npm run build`를 실행하고 관련 검사 결과를 확인한다. 변경과 무관한 테스트를 반복 실행하지 않는다.
- 결과 보고는 구현된 단계/문항 수, 수정 파일, 실제 검증, 적용이 필요한 DB 변경이나 남은 검수를 짧게 알린다. 기술 검수를 사용자 외형 승인으로 기록하지 않는다.
