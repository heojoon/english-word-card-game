# 월드 10 외3 · 크리스털왕

사용자는 첨부한 크리스털왕을 외3 보스로 지정했고, 스탠딩·SD·소환 스킬·조우/승리 이야기와 실제 게임 적용 범위에 `구현`으로 진행을 지시했다. 배포는 요청되지 않았다.

- `story-ch10-extra-3` 기록 ID와 기존 완료 기록명 `스토리 10장 번외 3 · 별빛이 끊긴 관측탑`을 보존한다. 표시 이름과 조우 대상만 크리스털왕으로 교체한다. HP 180, Type C, 30문항 순환, 접촉 시 현재 DMG, 기존 시간·보상·선택 경로 규칙 유지. 새 DB/보상 변경 없음.
- 사용자 그림의 금 왕관, 흰 털 장식, 짙은 자주색 망토, 보라·분홍 수정 갑옷과 큰 수정 검을 유지한다. 스탠딩과 왼쪽 방향 SD idle/attack/hit/skill 각각 3프레임 제작. 448×384 셀, 앵커 (0.5, 0.975), 실제 RGBA. 넓은 검·부유 수정·다운 자세 때문에 기존 월드10 보스의 확장 셀을 사용한다.
- 제작자 수치 결정: 20초마다 크리스털 소환. 1.2초 준비 후 HP 1 피해, 1.5초에 종료. HP 50% 통과 시 같은 소환을 한 번 추가 예약. 중복 예약/진행 중 공격 끼어들기 방지, 공용 방어와 시간정지 적용. 오답은 수정 검 공격으로 550ms에 HP 1 피해.
- 기존 월드10 모듈과 렌더러에 `crystal-king`을 추가한다. 임시 아스트라 렌더링 유지안 대신 전용 자산·전투 전체 교체안을 사용자가 선택했다. 다른 보스는 유지한다.
- 폐신호소 아래 수정 방의 수호자로 등장하고 오해를 풀어 길을 내주는 이야기로 교체한다. 새 유물·전용 보상 없음.
- 관련 회귀 검사, 오프라인 투명도·프레임·밝은/보라 배경 검수, npm run build. 브라우저 검사는 요청되지 않았으므로 실행하지 않는다. 기술 검수를 사용자 외형 승인으로 기록하지 않는다.
