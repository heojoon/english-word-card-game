# 케우르스 SD 전투 애니메이션

- 정체성 기준: `assets/novel/characters/char_keurus_world7a_standing.webp` (현재 작업 트리의 기존 캐릭터 아트).
- 제작: built-in imagegen으로 투명 SD 대기, 거암 내려찍기 접촉, 완전 다운 자세를 각각 생성. `source/`에 원본을 보관한다. `scripts/assemble-keurus.py`가 정규화 프레임과 런타임 스트립을 재생성한다.
- 대기 2프레임, 공격 3프레임, 피격/다운 3프레임. 전 프레임 왼쪽 방향. 런타임 셀 512 × 320, 아래 중앙 앵커 (0.5, 0.975), 지면선 y=312. 공격 접촉은 3프레임, 피격 최종 프레임은 완전 다운 상태로 유지한다.
- `review/*-source-50px.png`는 프레임 사이 50px 투명 간격을 둔 검수용이며 런타임 스트립은 빈 간격 없이 이어 붙인다. `review/mobile-light-violet.png`에서 밝은 배경과 Crystal Violet 배경의 모바일 크기를 확인했다.
- 기술: 거암 내려찍기 30초 주기, 접촉 0.7초 전 예고 후 HP 1 피해. 쌍두 교란 20초 주기, 아직 남은 카드만 재배열. 5분 제한, 연결형 30쌍. 스킬 시계는 아이스 타임과 펫 시간 정지에서 멈춘다.
- 검토 상태: 프레임 순서, 실제 알파, 배경별 시각, 런타임 크기와 빌드 확인. 사용자 아트 승인이나 브라우저 플레이 검수는 주장하지 않는다.
