# 월드 7A 해골 병사

- `normal`: 1~14단계의 상아색 해골 병사. 보랏빛 눈, 짧은 검, 허리띠, 철제 어깨 보호대.
- `scorched`: 16~29단계의 그을린 해골 병사. 같은 병사에 그을음과 작은 호박색 불씨를 추가한다.
- 15·30단계는 보스 지점으로 유지한다. 붉은 눈·망토·불타는 검은 보스의 특징이다.

각 형태는 대기 2프레임, 공격 3프레임, 피격/쓰러짐 3프레임의 RGBA PNG를 사용한다. 검과 뼈 무더기를 자르지 않도록 넓힌 셀 416×320, 바닥 y=312, 앵커 (0.5, 0.975). 공격은 마지막 프레임에서 접촉하고, 피격은 알아차림 → 반동 → 뼈 무더기로 쓰러짐 순서이며 마지막 프레임을 유지한다. 공유 Story 몹 재생기가 접촉 시점, 타깃 한 마리 처치, 일시정지, 아이스 타임 대기 정지와 동작 줄이기를 처리한다.

제작 계약은 `animation-contract.json`, 전체 프롬프트와 참조는 `*.generation.json`에 보관한다. 생성 원본은 `source/*-generated.png`, 추출 프레임은 `source-frames/`, 정규화 프레임은 `<variant>/<action>/`, 런타임 시트와 JSON은 이 폴더에 둔다. `source/*-master-50px.png`와 `review/*-source-50px.png`는 프레임 사이 정확히 50px 투명 간격을 둔 검수용이며 런타임에는 사용하지 않는다.

재조립: `python scripts/assemble-world7a-skeleton.py` (Pillow 필요). 흰 뼈를 보존하도록 색상 키잉 없이 알파만 정리한다. 밝은 배경과 Crystal Violet 배경의 검수 이미지, 미리보기 애니메이션과 경계 검증 결과는 `review/`에 보관한다. 브라우저 검수와 사용자 외형 승인은 별도이며 수행했다고 간주하지 않는다.
