# 월드 7B 검은 도마뱀 창병

검은 비늘·호박색 눈·회색 배·굵은 꼬리, 짧은 가죽 허리옷과 은빛 어깨 보호대를 갖춘 창병. 사용자 지정 일반 몬스터로 1~14·16~29단계에 적용하며 15·30단계 보스는 제외한다.

- 대기 2프레임: 준비 → 호흡/눈 깜박임.
- 공격 3프레임: 준비 → 창을 뒤로 당김 → 왼쪽 찌르기 접촉. 공격 시작 240ms에 피해, 동작 줄이기에서는 90ms.
- 피격 3프레임: 알아차림 → 강한 반동 → 완전히 쓰러짐. 플레이어 접촉 시점에 반동을 맞추고 마지막 자세를 처치 전환까지 유지한다.
- 런타임 RGBA PNG는 480×320 셀, 바닥 y=312, 앵커 (0.5, 0.975). 창·꼬리를 위해 가로 셀을 넓히며 표기 크기는 153×102px이다.
- 공유 Story 재생기가 타깃 한 마리 처치, 접촉 진동, 일시정지, 아이스 타임 대기 정지, 동작 줄이기를 처리한다.

원본은 `source/`, 추출 프레임은 `source-frames/`, 정규화 프레임은 각 동작 폴더, 50px 투명 간격의 검수 시트와 밝은색/Crystal Violet 모바일 검수·미리보기는 `review/`에 둔다. 생성 원본의 간격은 생성 모델의 출력이며, 정규화된 제작용 source master와 review master에는 정확히 50px 간격을 적용한다. 공격 시트 초안은 창 방향과 꼬리 잘림으로 폐기하고 개별 생성 프레임으로 교체했다.

재조립: `python scripts/assemble-world7b-lizardman.py` (Pillow). 색상 키잉 없이 알파를 보존한다. 전체 프롬프트는 `animations.generation.json`과 `attack-repair.generation.json`, 제작 계약은 `animation-contract.json`에 기록한다. 브라우저 검수는 요청 시 별도로 진행한다.
