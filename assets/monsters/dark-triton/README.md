# 다크 트라이튼 — 7B 최종보스 제작 자산

검은 호수의 메아리에 잠식된 인어 왕. 한때 호수의 노래와 물길을 지키던 수호자였지만 이제 조개 왕좌에 군림하며 크리스털 삼지창으로 검은 물결을 다스린다. 왕의 명령을 꺾어야 심연의 세이렌 지팡이로 향하는 길이 열린다.

| 항목 | 명세 |
| --- | --- |
| 위치 | 7B 30단계 최종보스 |
| HP | 220 |
| 제한 시간 | 5분 / 300초 |
| 문제 | 연결문제 |
| 스톰서지 | 매 10초 해일 투사체 발사 → 접촉 시 카드 무작위 섞기 |
| 트라이던트 쓰루 | HP 50·40·30·20·10% 통과 시 각 1회, 삼지창 투척 → 접촉 시 플레이어 HP 1 감소 |

스탠딩 CG와 SD는 같은 얼굴·은백색 머리와 수염·파란 수정 왕관·흑청색 갑옷·인어 꼬리·삼지창을 유지한다. 보스는 노년의 인어 왕이며 SD 비율만 축약한다. 다리나 부츠를 추가하지 않는다.

## 파일

- `dark-triton-standing.png`: 여백을 확보한 투명 스탠딩 CG.
- `source/standing.png`: 첫 생성 원본. 삼지창 상단 여백 결함이 있어 런타임 사용 금지.
- `source/identity.png`: SD 외형 기준 원본.
- `source/*-generated.png`: 행동별 생성 원본, 수정하지 않고 보존.
- `source/*-master-50px.png`: 추출 프레임을 정확히 50px 간격으로 재배치한 제작 마스터.
- `source-frames/<action>/`: 추출된 프레임.
- `<action>/`: 480×320 정규화 RGBA 프레임.
- `*_strip.png` 및 같은 이름의 JSON: 빈 간격 없는 가로 스트립과 타이밍·이벤트·앵커 명세.
- `review/`: 밝은 배경·Crystal Violet 배경의 모바일 크기 검수, 정확한 50px 간격 시트, 애니메이션 WebP.
- `preview.html`: 상태별 프레임 재생 및 두 스킬의 캐릭터/투사체 접촉 타임라인을 검토하는 독립 미리보기.
- `source/generation-prompts.json`: 사용한 전체 프롬프트와 참조 경로. 기본 내장 `image_gen` 사용.
- `source/generation-review.json`: 개별 프레임 재생성까지 포함한 최종 전체 프롬프트·참조·채택/제외 기록.

## 재생 계약

캐릭터는 왼쪽을 향하고 480×320 셀의 바닥 중앙 `(0.5, 0.975)`에 고정한다. 긴 꼬리와 삼지창을 수용하기 위해 기본 셀보다 넓다. 투사체는 독립된 `(0.5, 0.5)` 앵커를 사용한다. 이동은 화면 공간에서 별도로 처리한다.

대기는 2프레임 반복, 해일 시전과 삼지창 투척은 각각 3프레임이다. 각 공격 마지막 프레임에서 `release` 후 투사체를 재생하고, 투사체 세 번째 `contact` 프레임에서만 카드 섞기 또는 HP 감소를 적용한다. 해일 자체에 추가 피해를 부여하지 않는다. 투척 전 삼지창은 손에 있으며 투척 후 캐릭터 손에서 사라지고 별도 투사체로 이동한다. 대기 복귀 시 마법으로 무기가 재생성되는 계약이다.

피격은 `알아차림 → 가장 강한 반동 → 완전히 쓰러짐`의 정확히 3프레임이다. 마지막 프레임은 상태 전환 전까지 유지하며 내부에서 일어나지 않는다. 동작 줄이기는 준비·발사·접촉 순서를 보존하며 시간을 단축한다. 아이스 타임·일시정지에서는 대기 모션과 전투 시계를 함께 멈추되 공격 접촉 피드백은 유지해야 한다.

CSS로 N프레임을 재생할 경우 `background-size: N00% 100%`, `steps(N - 1, end)`, 위치 `0 → 100%`를 사용한다. JSON의 프레임별 시간을 정확히 따르려면 프레임 인덱스 재생기를 사용한다.

## 검수 범위

사용자의 적용 요청에 따라 7B 30단계의 보스 소개·전투·스토리 대사에 연결했다. 전투 코드는 `dark-triton-boss.js`와 `crystal-game.js`, 타이밍·스킬·아이스 타임·정리 및 재사용 회귀 테스트는 `tests/dark-triton-boss.test.mjs`에 있다. 전용 보상 수치는 추가하지 않고 기존 Story 결과 저장과 진행 기록을 유지한다. 운영 DB 변경과 배포는 하지 않았다. 오프라인 투명도·셀 경계·프레임별 시각 검수 기록은 `review/validation.json`에 보관한다. 브라우저 검수는 요청받지 않아 실행하지 않았다.

재조립: `python scripts/assemble-dark-triton.py` (Pillow 필요).

오프라인 규격 확인·레이어 합성 미리보기 재생성: `python scripts/review-dark-triton.py`.
