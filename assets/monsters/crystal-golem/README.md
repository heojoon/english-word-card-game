# 크리스탈 골렘 이미지

- `crystal-golem-midboss.png`: 금장과 민트색 코어가 있는 기존 골렘. **중간보스 전용**이며 월드 2 프롤로그의 사원 수호자 등장 CG로 사용한다.
- `crystal-golem-normal.png`: 금장, 갑옷, 문양, 장식을 모두 제외한 푸른 크리스탈 몸체의 **일반 몬스터**.

두 이미지는 투명 배경의 단일 전신 일러스트다. 전투 애니메이션 스트립은 별도로 제작해야 한다.

- `crystal-golem-normal-sd-right.png`: 사용자 제공 일반 골렘을 SD 전신으로 수정한 월드 2 일반 전투 자산. 원본은 오른쪽 방향이며 전투에서는 이미지 레이어를 좌우 반전해 왼쪽의 플레이어를 바라본다. 기존 웨이브의 대기·공격·피격 CSS 연출을 사용하며, 개별 포즈 애니메이션 스트립은 아니다. 월드 1 슬라임과 중간보스 CG는 유지한다.
- 편집 프롬프트와 출력 계약: `crystal-golem-normal-sd-right.json`.

생성 도구 및 최종 프롬프트는 `generation.json`에 기록한다. 중간보스 원본 프롬프트는 `../../story/chapter-2-prologue/generation-prompts.json`에도 보존한다.
