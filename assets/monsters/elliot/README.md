# 엘리엇 · 월드 6B 20단계

첨부 원본은 `source/user-reference.png`, 추출 스탠딩 원본은 `source/standing-generated.png`, 스토리용 출력은 `../../novel/characters/char_elliot_world6b_standing.webp`입니다. 이름은 기존 대본의 엘로잇에서 요청한 엘리엇으로 통일했습니다.

`image_gen` 내장 도구로 제작했습니다. 전체 프롬프트와 참조는 `source/generation-prompts.json`, 프레임 계약은 `animation-contract.json`, 정규화 좌표는 `source/layouts.json`에 있습니다. 프레임 간격이 부족하거나 효과가 잘린 최초 3컷 원본은 보관만 하고, 동작을 단독 생성한 프레임으로 교체했습니다. 방패 첫 준비 프레임은 완전한 첫 슬롯을 추출했습니다. 새로 생성된 프레임에서는 검/머리/옷/발을 보존하고, 정규화 시 alpha 8 이하의 미세한 생성 노이즈만 제거했습니다. 흰 옷을 색상 키로 제거하지 않았습니다.

대기, 오러 소드, 광휘의 방패, 피격/다운은 각각 3프레임입니다. 런타임은 448×320 RGBA 셀 3개가 연속된 PNG입니다. 긴 검과 망토를 위해 320px보다 넓은 셀을 사용합니다. 본체 크기는 SD 기준 원화의 머리 크기에 맞추고, 자세가 낮아지는 돌진/다운에서 키를 늘리지 않습니다. 발 기준선은 y=300이며, 아래쪽 검 끝/오러 여백을 남깁니다. 앵커는 (0.5,0.975)입니다.

오러 소드는 180ms 준비 → 220ms 돌진 → 180ms 접촉입니다. 피해는 400ms 접촉 프레임에 한 번 판정합니다. 20초 주기이며, 1분 시점에 방패와 겹치면 방패 동작 후 대기 중인 검 공격을 실행합니다. 방패는 1분 간격, 10초 피해 무효입니다. 정답 수는 방어 중에도 기록합니다. 아이스 타임과 펫 시간 정지는 전투 시계/보스 동작/방패 시간을 함께 정지시키며 플레이어 공격 접촉 피드백은 완료합니다.

보스 HP 500, 제한시간 300초, 최초 보상 800 크리스털입니다. **플레이어 생존 + 300초 도달 + 보스 HP 250 이하**를 모두 만족해야 합니다. HP 0 도달도 시험을 조기 종료하지 않으며, 성공은 스승의 인정이므로 보스의 쓰러짐 대신 기존 승리 대본으로 전환합니다. 비치명 피격은 hit 2번 프레임을 사용하고, 준비된 hit 3번 다운 프레임은 재생 시 마지막 프레임을 유지합니다.

`review/`에는 밝은색/Crystal Violet 원본 크기 합성, 모바일 크기 그리드, 정확히 50px 투명 간격의 마스터, 애니메이션 WebP와 검증 결과가 있습니다. 흰 의상, 전체 검/망토/발, 각 슬롯 경계와 바닥선을 확인했습니다. 런타임은 동일 시계에서 매 프레임 위치를 선택하므로 CSS 독립 반복 재생에 따른 접촉 시점 오차가 없습니다.

브라우저 검증은 요청되지 않아 수행하지 않았습니다. 기술 검토를 사용자 승인으로 간주하지 않습니다.
