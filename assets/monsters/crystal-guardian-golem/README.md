# 크리스탈 가디언 골렘

월드 2 스테이지 7 전용 보스. 원형은 사용자가 제공한 `source/identity-original.png`이다.

- `crystal-guardian-standing-left.png`: 왼쪽을 바라보는 스토리 CG.
- `crystal-guardian-sd-left.png`: SD 대기 첫 프레임.
- `crystal-guardian-sd-*-strip.png/json`: 대기 2프레임, 크리스탈 빔 3프레임, 피격/쓰러짐 3프레임. 320×320 RGBA 셀, 아래 중앙 앵커 `(0.5, 0.975)`.
- 일반 피격은 첫 두 프레임만 재생한다. 보스 처치 시 3프레임을 재생하고 완전히 쓰러진 마지막 프레임을 스토리 전환까지 유지한다.
- 빔은 충전 300ms → 조준 300ms → 발사/접촉 300ms. 감소 모션은 각 구간을 절반으로 줄인다. 답안 가림은 두 경우 모두 접촉 후 정확히 5초이다.
- 발사체는 CSS 레이어로 가슴에서 왼쪽 플레이어 방향으로 표시한다.
- `source/`: 생성 원본. 붙어 나온 피격 시트는 폐기 표시하고 개별 피격/쓰러짐 원본으로 교체했다.
- `source-frames/`, `idle/`, `attack/`, `hit/`: 추출 원본과 정규화 프레임.
- `review/`: 정확한 50px 투명 간격의 검수 시트, 밝은/보라색 배경 160px 검수 이미지, 애니메이션 WebP.
- 재조립: `python3 scripts/assemble-guardian-sprites.py` (Pillow 필요).

보스 로직은 `guardian-boss.js`, 화면/전투 연결은 `crystal-game.js`와 `crystal-game.css`에 있다. 초등 `e14`, 중등 `s14`의 각 20단어를 방향별 1회씩(40문제)과 추가 1회(20문제) 출제한다. 남은 에너지 48/24/12/6에서 빔을 1회씩 발동한다. 답안 가림과 공격 상태는 일시정지 중 진행되지 않는다. 처치 후 기존 종료 스토리를 표시하고 보상 화면으로 이동한다.

오프라인 이미지·알파·상태 전환 검수 완료. 브라우저 검수는 사용자의 요청이 있을 때만 진행한다.
