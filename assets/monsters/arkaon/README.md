# 월드 7C 10단계 — 봉인 병기 아르카온

인공 심연의 골렘. 왕국 지하 던전의 돌다리를 지키는 고대 마법 병기.
기존 7A·7B와 같은 Crystal Quest 일러스트·연결형 보스전 구성이다.

- HP 200, 제한 5분, 다섯 쌍 연결. 초등·중등은 기존 같은 번호 단어를 사용한다.
- 봉인 충격파: 20초마다 600ms 예고 후 지면 접촉. 35% 확률로 HP 1 피해. 축소 모션은 300ms 접촉.
- 마력 재배열: 30초마다 남은 카드만 재배열. 진행 중인 정답의 접촉 처리가 끝나고 섞으며, 맞힌 카드와 판의 단어는 보존한다.
- 아이스 타임은 실제 전투 시계·대기 동작·새 스킬 예약을 멈춘다. 시작한 공격은 접촉까지 표시한다.
- 기존 일반 전투 저장·보상 경로를 사용한다. 신규 일회성 보상이나 DB 권한은 추가하지 않았다.

CG: `assets/novel/characters/char_arkaon_world7c_standing.webp`.
SD 원형은 `source/identity.png`. CG와 SD는 별도 자산이다.
대기·공격·마력 재배열·피격/쓰러짐은 각각 3프레임이며 런타임 셀은 320×320, 앵커는 (0.5, 0.975).
공격은 마지막 프레임에 접촉하고, 피격의 마지막 완전 쓰러짐 프레임은 승패 전환까지 유지한다.
런타임은 전투 시계로 프레임을 직접 선택해 일시정지·축소 모션을 처리한다.

생성 원본과 추출 프레임, 50px 투명 간격의 마스터, 연속 런타임 스트립, 리뷰 이미지·애니메이션을 분리했다.
`python scripts/assemble-arkaon.py`로 재조립한다. 불투명 갑옷에 색상 키 처리를 하지 않으며 알파 8 이하의 생성 잡음만 제거한다.
첫 번째 마력 재배열 시트는 가장자리 여백 부족으로 거절했으며 `source/reorder-rejected-crowded.png`에 보존했다.
보정 프롬프트와 나머지 전체 프롬프트·참조 경로는 `source/reorder-correction-prompt.txt`, `generation.json`에 있다.

기술 검수: 12개 프레임을 밝은 배경과 Crystal Violet 배경의 실제 모바일 크기 합성으로 검사했다.
외곽·발·주먹·결정·스킬 효과의 런타임 잘림, 프레임 간 침범, 흰 갑옷의 투명 구멍이 없다.
원본 시트 간격은 생성 결과에 편차가 있어 추출 후 별도 마스터에서 정확히 50px를 보장했다.
브라우저 검수는 요청되지 않아 실행하지 않았다. 사용자 시각 승인을 받았다는 의미는 아니다.
