# 블랙 드래곤 · 월드 3 보스

- 위치: `story-ch3-8` 숨겨진 수정 동굴. 단계 기록은 기존 `스토리 3장 8 · 하늘 수정 성소`를 유지한다.
- 양방향 4지선다 60문제, 에너지 60, 제한시간 300초(5분). 학습 레벨은 단어만 변경한다.
- 에너지 48/30/12/6 (80/50/20/10%)를 통과하면 각각 한 번 흡수한다. 접촉 시 `random < 0.1`이면 HP 1 감소. 보스 에너지 회복은 없다.
- 진입 스토리 → 즉시 보스 → 승리 스토리 → 계정당 최초 600 크리스털. 패배 시 재도전/떠나기. 재도전은 HP/MP와 모든 전투 상태를 새로 만든다.
- 사용자 원본: `source/design-reference.png`. 생성 원본과 정규화 프레임·런타임·50px 간격 검수본은 분리한다. 원본 생성 시트의 간격은 모델이 정확히 지키지 않아 정규화 검수본에서 50px를 보장한다.
- 날개를 자르거나 몸을 축소하지 않도록 384×384 셀, 아래 중앙 앵커 `(0.5, 0.975)`. 대기 2, 공격 3, 피격/쓰러짐 3프레임. 최종 쓰러짐은 결과 전환까지 유지한다.
- 재조립: `python3 scripts/assemble-black-dragon-sprites.py`.
- 전체 프롬프트와 계약: `animation-contract.json`. 밝은/보라색 배경 알파와 셀 경계 검수 완료. 브라우저 검수는 사용자 요청 전 미실행. 기술 검수는 사용자 시각 승인을 뜻하지 않는다.
