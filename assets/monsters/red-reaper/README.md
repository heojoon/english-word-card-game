# 붉은 사신 · World 4-20

사용자가 선택한 `concepts/red-reaper-03.png`가 스토리 CG와 SD 디자인의 기준이다. 스토리 CG `red-reaper-standing.png`는 전투 스프라이트와 분리한다.

- 전투: HP 120, 340초, 5쌍 매칭. 고유 단어 주기를 소진한 뒤 반복하고 한 보드의 단어는 중복되지 않는다.
- 데스 할루시네이션: 활성 전투시간 20초마다 성공확률 60%를 판정. 3개의 겹쳐진 사신이 나타나며 200ms의 시전 접촉에서 성공 효과를 시작한다. 10초 동안 왼쪽(뜻) 카드를 300ms마다 아래로, 오른쪽(영어) 카드를 500ms마다 위로 순환한다. 카드 식별자·선택·정답 관계는 변하지 않는다.
- 일시정지는 모든 시간을 정지한다. 아이스 타임은 제한시간·스킬 주기·카드 이동을 정지하고 공격 접촉·피격은 진행한다. 오답·5쌍 완료·종료에서 해제한다.
- SD는 왼쪽을 향하는 448×320 RGBA 셀이다. 긴 낫 때문에 셀 너비를 늘렸으며 몸 높이는 약 235px, 기준선은 y=312이다. idle 2프레임, attack 3프레임, hit 3프레임. 최종 knockdown은 완전히 누운 상태로 유지한다.
- 원본은 `source/`, 개별 원본 프레임은 `source-frames/`, 정규화 프레임은 `idle/`, `attack/`, `hit/`, 정확히 50px 간격의 검수본·밝은/보라색 배경 합성·모바일 GIF는 `review/`에 보관한다. `scripts/assemble-red-reaper-sprites.py`로 재조립한다.
- 기술·프레임 검수 통과. 브라우저 검수는 요청되지 않아 미실행. SD 별도 사용자 승인과 기술 검수는 구분한다.
- 진입 소설 → 보스전 → 승리 소설 → 최초 500 크리스털. 패배는 재도전/떠나기 화면으로 연결된다. `claim_red_reaper_boss_reward`는 운영 DB에 적용됐으며 소유권·관리자 제한·120 처치·340초 상한·계정 지갑 잠금·중복 지급을 검증한다. 보상 검증 SQL은 실제 변경을 롤백한다.

- 전투 몸체는 좌우 1cm 범위로 8초 주기로 움직이며 게이지는 고정된다. 아이스 타임·일시정지·최종 쓰러짐에서는 이동을 멈춘다.
- 공격 중 다음 카드 쌍을 일반 몬스터 전투와 같은 대기열로 연속 선택할 수 있다. 피해는 각 공격 접촉에 순서대로 적용된다.

- 데스 할루시네이션 성공 시 분신과 시전 마지막 자세를 효과 지속 10초 동안 유지한다. 실패 시 시전 종료에 분신이 사라지며, 성공 효과 종료·전투 종료에서도 분신을 해제한다. 피격·최종 쓰러짐 피드백은 우선 표시한다.
