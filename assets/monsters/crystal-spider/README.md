# 크리스탈 거미 · 월드 5

사용자가 선택한 1안(수정갑각형)을 기준으로 제작한 전투 자산이다.
`design-reference.png`는 승인된 디자인 원본이며 애니메이션은 별도 제작물이다.

- 대기: 2프레임, 600ms씩 반복.
- 공격: 준비 → 웅크림 → 앞다리 찌르기. 접촉은 240ms(동작 줄이기 90ms).
- 피격: 경계 → 충격 → 완전 쓰러짐. 플레이어의 실제 접촉 시점에 충격 프레임을 맞추며 마지막 프레임을 유지한 후 해당 몬스터만 제거한다.
- 런타임: 수평 RGBA PNG, 셀 320×320, 앵커 (0.5, 0.975), 바닥 y=312.
- 월드 5 일반 연결하기 전투에 적용한다. 현재 일반 전투 규칙을 쓰는 10·20단계에도 같은 몬스터가 표시된다. 보스 패턴은 추가하지 않는다.
- 아이스 타임은 대기 동작만 멈추며 타격·쓰러짐은 재생한다. 일시정지는 접촉·제거 타이머와 동작을 함께 멈춘다.

`source/`는 내장 image_gen 생성 원본과 정확히 50px 간격으로 다시 조립한 고해상도 마스터,
`source-frames/`는 분리한 원본 프레임, 각 동작 폴더는 정규화한 프레임이다.
생성된 원본 시트의 간격은 요청과 달라 프레임별 추출 후 마스터를 재조립했다.
피격 2번은 인접 프레임과의 경계 여유가 부족해 단독 이미지로 재생성했다.
알파 기반의 작은 분리 조각 정리만 사용했으며 흰색·보라색 색상 제거는 하지 않았다.
원본 해상도가 다른 시트는 서 있는 몸통 크기를 기준으로 배율을 맞췄고, 각 동작 내에서는 동일 배율과 바닥선을 유지한다.

재조립: `python scripts/assemble-crystal-spider-sprites.py` (Pillow 필요).
전체 프롬프트와 제작 규격은 `animation-contract.json`에 기록했다.
밝은 배경·Crystal Violet 배경과 128px 크기는 `review/*-mobile-light-violet.png`에서 검수했다.
브라우저 검증은 사용자 요청이 없어 실행하지 않았다. 애니메이션에 대한 사용자 승인을 추정하지 않는다.
