# 모르가나 — 월드 6A 최종 보스

- 위치: 반전세계 20단계. 초등·중등의 기존 공통 진행 기록과 각 레벨 어휘를 유지한다.
- 소개: 심연의 주인. HP 200, 제한시간 5분, 최초 처치 보상 500 크리스털.
- 문제: 다섯 쌍 연결하기. 영어·한글의 정체성과 정답 ID는 배치가 바뀌어도 유지한다.
- 혼돈의 저주: 전투 시간 20초마다 반드시 발동, 10초 지속. 열에 상관없이 열 장을 섞는다. 왼쪽 열은 위로, 오른쪽 열은 아래로 0.8초마다 한 칸씩 순환한다. 같은 열에서도 정답 쌍을 고를 수 있다. 선택한 카드는 이동해도 선택을 유지한다. 새 보드도 저주가 남아 있으면 섞는다.
- 저주 연출: 플레이어를 초당 한 바퀴 회전시킨다. 공격 이동·접촉 프레임은 기존 애니메이션으로 유지한다. 동작 줄이기 설정에서는 회전과 카드 이동 보간을 생략하고 상태 안내와 실제 배치 변경을 유지한다.
- 리프레시힐: HP 60 이하에 도달하는 첫 타격에서 HP 200으로 회복한다. 정확히 한 번만 사용한다. 흰빛 원과 네 개의 별빛이 1.6초 동안 보스를 감싼다. 큰 피해로 임계값을 지나쳐도 한 번은 회복한다.
- 아이스 타임·펫 시간 정지·일시정지에서는 저주의 주기, 이동, 플레이어 회전도 멈춘다. 아이스 타임은 오답 또는 현재 다섯 쌍 완료 시 해제된다.
- 이미지: `source/user-reference.png`는 사용자 원화이며 소개용 `morgana-standing.webp`로 별도 보존한다. 내장 image_gen으로 제작한 전투용 SD 원본은 `source/identity.png`, 정규화한 투명 런타임은 `morgana-sd.png`다. 생성 프롬프트와 검토 상태는 `generation.json`, 애니메이션 계약은 `morgana-sd.json`에 기록한다.
- 보상: `claim_morgana_reward`가 소유권, 6A 분기, 19단계 클리어를 확인한다. 계정 지갑을 잠그고 영수증을 확인해 캐릭터를 바꿔도 중복 지급하지 않는다. 패배·재도전·상자·콤보로 추가 보상하지 않는다.
- 서버 검증: 연결된 운영 DB에서 트랜잭션 안에 첫 지급 500, 재지급 0, 패배 0, 타인 캐릭터 거부를 확인한 뒤 전부 롤백했다. 보상 RPC의 authenticated SECURITY DEFINER 권한은 계정 지갑 원자적 갱신을 위한 의도된 권한이며 함수 내부에서 인증·소유권을 검사한다.
- 브라우저 검증과 사용자 미술 승인은 아직 진행하지 않았다.
- 스토리 스탠딩 CG: `assets/novel/characters/char_morgana_world6a_standing.webp`. 원화의 일반 비율과 정체성을 유지해 배경 없이 제작했으며, 최종보스 시작·승리 후 대화·살림/죽임 결말에서 사용한다. 배경 포함 소개 원화와 전투 SD는 별도로 유지한다. 생성 원본·프롬프트·검수 기록은 `assets/novel/characters/source/morgana-standing-generated.png` 및 `char_morgana_world6a_standing.generation.json`에 보존한다.
