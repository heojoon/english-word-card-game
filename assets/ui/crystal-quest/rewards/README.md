# Crystal Quest reward chests

## Production default

- `ui_reward_chest_guardian_closed.webp`: runtime Guardian Prism chest, closed state.
- `ui_reward_chest_guardian_open.webp`: matching runtime open state with an empty magical-light interior for compositing future rewards.
- The matching `.png` files are the lossless generation originals.
- `ui_reward_crystal_bloom.webp`: approved runtime crystal reward, a full violet/mint/white crystal bloom cluster.
- `ui_reward_crystal_bloom.png`: lossless generation original for the crystal reward.

## Reserved special-reward concepts

- `concepts/ui_reward_chest_arcane_ring_closed.png`: magical or arcane reward.
- `concepts/ui_reward_chest_starlight_crown_closed.png`: celebration or achievement reward.
- `concepts/ui_reward_chest_voyager_closed.png`: exploration or event reward.
- `concepts/ui_reward_chest_geode_closed.png`: rare or premium reward.

The concept files are preserved as source candidates. Normalize transparency, runtime dimensions, and matching open states before integrating any of them into production.
