# 월드 7C · 왕국 지하 던전 전투 배경

`01-royal-dungeon-battle.webp`는 일반 전투용 배경이다. 기존 7C 지도에서 크림색 석조, 청록색 수로, 푸른 지하 공간, 황금 조명과 고대 마법 장치를 이어받았다. 넓은 평면 전경을 남겨 전투 캐릭터와 학습 UI의 가독성을 확보했다.

생성 원본은 `source/royal-dungeon-battle.png`, 전체 프롬프트·참조·내장 image_gen 제작 기록은 `generation.json`에 있다. 원본과 WebP는 같은 크기이며 비율 변경이나 업스케일은 하지 않았다.

몬스터와 합성한 미리보기는 `assets/monsters/world-7c/review/index.html`에서 확인할 수 있다. 본 게임 7C의 30개 단계에 전투 배경으로 연결했다. 오프라인 구도 검수 완료. 브라우저 검수는 요청하지 않아 수행하지 않았다.
