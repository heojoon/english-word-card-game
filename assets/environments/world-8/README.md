# 월드 8 · 은종 마을 전투 배경

- `01-silver-bell-village-battle.webp`: 일반전, 1–14 / 16–29단계. 강가 마을 길.
- `02-blackroot-bridge-battle.webp`: 15단계 검은뿌리 거목. 뿌리에 잠긴 돌다리 앞.
- `03-vargas-bell-tower-battle.webp`: 30단계 바르가스. 파손된 종루 광장.

내장 image_gen으로 제작했다. 기존 7B 전투 배경의 회화적 마감과 월드 8 지도의 마을 건축·재료를 참조했다. 캐릭터는 배경에 포함하지 않고 기존 SD 애니메이션을 사용한다. 전경은 평탄한 전투 공간으로 비웠다.

원본은 `source/`, 전체 프롬프트와 참조는 `generation.json`에 보존한다. WebP는 원본 크기를 유지한다. `crystal-game.css`의 월드 8 일반전 및 보스별 선택자에 연결했다. 이미지 구도는 검수했으며 브라우저 검수와 사용자 화풍 승인은 별도다.
