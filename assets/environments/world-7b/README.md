# 월드 7B 전투 배경

내장 `image_gen`으로 생성한 1672 × 941 배경 3장입니다.

| 런타임 WebP | 적용 단계 | 장면 |
|---|---|---|
| `01-black-lake-ruins-battle.webp` | 1–14, 16–29 | 수중 폐허·수문 통로 |
| `02-nereus-bridge-battle.webp` | 15 | 네레우스가 지키는 궁전 앞 다리 |
| `03-siren-throne-battle.webp` | 30 | 검은 세이렌 대왕의 조개 왕좌실 |

`source/`에 생성 PNG 원본, `generation.json`에 전체 프롬프트·참고 이미지·검토 상태를 보관합니다. 기존 월드 5 전투 배경은 화풍과 전투 구도, 7B 지도는 수중 지역의 재질과 건축 참고로 사용했습니다. 지도 자체는 수정하지 않았습니다.

`storyBattleBackgroundClass()`와 CSS의 `world-seven-b-*` 규칙으로 연결하며, 전용 네레우스 렌더러에도 중간보스 배경 클래스를 적용합니다. 캐릭터와 공격 효과는 기존 별도 레이어를 유지합니다. 이미지 시각 검토 완료. 브라우저 검사는 요청되지 않아 실행하지 않았으며 사용자 승인 상태를 뜻하지 않습니다.
